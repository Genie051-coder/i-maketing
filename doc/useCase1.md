# Use Case 1 — 뉴스레터 이메일 발송

> **시나리오**: 첫 이메일 발송 테스트  
> **수신자**: `sjlim@ideatec.co.kr`  
> **전제 조건**: Gmail 연동 완료 상태  

---

## 전체 흐름 요약

```
[STEP 1] /ko 홈 — 제목 입력 + 이메일 클릭 + 전송
      ↓
[STEP 2] /ko/flow/[flowId] — 플로우 편집기 (5개 노드 자동 배치)
      ↓
[STEP 3] 캠페인 목적 노드 → 뉴스레터 선택
      ↓
[STEP 4] 이메일 작성 노드 → 편집 탭 → 텍스트 블록 추가 → 본문 입력
      ↓
[STEP 5] 주소록 노드 → sjlim@ideatec.co.kr 입력
      ↓
[STEP 6] 발송 설정 노드 → 제목 "테스트 이메일" 입력 → 저장
      ↓
[STEP 7] 발송 확인 노드 → 자동 검증 통과 → 지금 발송하기
```

---

## STEP 1 — 홈 화면 (`/ko`)

```
┌─────────────────────────────────────────────────────────────────────┐
│  ┌──────────┐                                                        │
│  │ ◈ 앱이름  │  [홈]                                                 │
│  │          │                                                        │

│                                                                      │
│              어떤 캠페인을 만들어 볼까요?                             │
│              AI가 콘텐츠 작성을 도와드려요                            │
│                                                                      │
│   ┌─────────────────────────────────────────────────────┐           │
│   │  ✏️  첫 이메일 발송 테스트                   [↑ 전송] │           │  ← 제목 입력됨
│   └─────────────────────────────────────────────────────┘           │
│                                                                      │
│   ╔══════════════╗                                                   │
│   ║  ✉ 이메일   ║  [ 📝 블로그 ]  [ 📣 페이스북 ] ...              │  ← 이메일 선택 (검정 배경)
│   ╚══════════════╝                                                   │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

### 조작 순서

1. 입력창에 캠페인 제목을 입력합니다.  
   → `첫 이메일 발송 테스트`

2. **`✉ 이메일`** 칩을 클릭합니다.  
   → 칩이 검정 배경 + 흰 텍스트로 강조됩니다.

3. **`↑ 전송`** 버튼을 클릭하거나 `Enter` 를 누릅니다.  
   → `POST /api/flow` 요청 → DB에 플로우 생성 → `/ko/flow/[id]` 로 자동 이동

## 전체 실행 흐름 다이어그램

```
/ko 홈
  │
  ├─ 제목 입력: "첫 이메일 발송 테스트"
  ├─ 유형 선택: [✉ 이메일] 클릭
  └─ [↑ 전송]
        │
        ▼
  POST /api/flow  { title, type: "email" }
        │
        ▼
  DB 플로우 생성 → redirect /ko/flow/[flowId]
        │
        ▼
  GET /api/flow/[flowId]  →  initFromDefinition()
  5개 노드 자동 배치 (모두 회색 점선 상태)
        │
        ├── STEP 3: [캠페인목적] 클릭
        │     → 뉴스레터 카드 클릭
        │     → saveNodeConfig({ campaignType: 'newsletter' })
        │     → PATCH /api/flow/[flowId]  ← DB 자동저장
        │
        ├── STEP 4: [이메일작성] 클릭
        │     → 편집 탭 선택 (기본값)
        │     → 블록 추가 탭에서 T 텍스트 클릭
        │     → 블록 편집 탭 자동 이동
        │     → Textarea에 "첫 이메일 발송" 입력
        │     → 모달 닫기
        │     → saveNodeConfig({ blocks: [{ type: 'Text', content: '첫 이메일 발송', level: 'body' }] })
        │     → PATCH /api/flow/[flowId]  ← DB 자동저장
        │
        ├── STEP 5: [주소록] 클릭
        │     → "sjlim@ideatec.co.kr" 입력 → 저장
        │     → saveNodeConfig({ recipientEmail: 'sjlim@ideatec.co.kr' })
        │     → PATCH /api/flow/[flowId]  ← DB 자동저장
        │
        ├── STEP 6: [발송설정] 클릭
        │     → 제목: "테스트 이메일" 입력
        │     → 발송 시간: 즉시 발송 선택
        │     → 저장 클릭
        │     → saveNodeConfig({ subject: '테스트 이메일', sendMode: 'now' })
        │     → PATCH /api/flow/[flowId]  ← DB 자동저장
        │
        └── STEP 7: [발송확인] 클릭
              → 자동 검증 (800ms)
                  ✅ Gmail 연동
                  ✅ sjlim@ideatec.co.kr 유효
                  ✅ "테스트 이메일" 제목 입력
                  ⚠️  미리보기 없음 (경고만)
                  ✅ 뉴스레터 체크리스트
              → "지금 발송하기" 클릭
              → 확인 다이얼로그 → "발송하기" 클릭
              → POST /api/email/send { nodes }
                    │
                    ▼
              runConfirmSendNode()
                    ├─ email 노드 blocks → React Email HTML 렌더링
                    │     └─ Text 블록: "첫 이메일 발송"
                    ├─ DB에서 GMAIL ExternalToken 조회
                    └─ Nodemailer → Gmail SMTP
                          → To: sjlim@ideatec.co.kr
                          → Subject: 테스트 이메일
                          → Body: 첫 이메일 발송
                                │
                                ▼
                          ✅ 발송 완료!
```
