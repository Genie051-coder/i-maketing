## 전체 흐름 요약

```
[1] /ko 홈 화면
      ↓  캠페인 제목 입력 + 이메일 선택 + 전송
[2] /ko/flow/[flowId] — 플로우 편집기 진입
      ↓  자동 배치된 5개 노드 확인
[3] 캠페인 목적 노드 클릭 → 유형 선택
      ↓
[4] 이메일 작성 노드 클릭 → AI 어시스턴트로 콘텐츠 생성
      ↓
[5] 주소록 노드 클릭 → 수신자 이메일 입력
      ↓
[6] 발송 설정 노드 클릭 → 제목·미리보기·발송 시간 설정
      ↓
[7] 발송 확인 노드 클릭 → 자동 검증 통과 → 발송 실행
```

## STEP 1 — 홈 화면 (`/ko`)

```
┌─────────────────────────────────────────────────────────────────────┐
│  ┌──────────┐                                                        │
│  │ ◈ 앱이름  │  [홈]                                                 │  ← 왼쪽 사이드바
│  │          │                                                        │
│  │ 오늘     │                                                        │
│  │ 어제     │                                                        │
│  │          │                                                        │
│  │ [프로필] │                                                        │
│  │ [설정]   │                                                        │
│  └──────────┘                                                        │
│                                                                      │
│              어떤 캠페인을 만들어 볼까요?                             │  ← 중앙 헤더
│              AI가 콘텐츠 작성을 도와드려요                            │
│                                                                      │
│   ┌─────────────────────────────────────────────────────┐           │
│   │  ✏️  캠페인 제목을 입력하세요...              [↑ 전송] │           │  ← ChatInput
│   └─────────────────────────────────────────────────────┘           │
│                                                                      │
│   [ ✉ 이메일 ]  [ 📝 블로그 ]  [ 📣 페이스북 ]  [ 📷 인스타 ]  [ 💬 SMS ] │  ← 유형 선택 칩
│                                                                      │

│                                                                      │
│   [ 신제품 런칭 이메일 ]  [ 여름 시즌 세일 ]  [ 뉴스레터 6월호 ]      │  ← 예시 버튼

### 조작 방법

1. **입력창**에 캠페인 제목을 입력합니다.  
   예) `6월 신제품 런칭 이메일`
2. 하단 칩에서 **`✉ 이메일`** 을 클릭합니다. (선택된 칩은 검정 배경으로 강조됨)
3. 입력창 오른쪽 **`↑ 전송`** 버튼 또는 `Enter` 를 누릅니다.

> **비로그인 상태라면** AuthModal(로그인/회원가입 팝업)이 뜹니다. 로그인 완료 후 자동으로 캠페인이 생성됩니다.

## STEP 2 — 플로우 편집기 진입 (`/ko/flow/[flowId]`)

캠페인 생성 직후 플로우 편집기로 자동 이동합니다.

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│  ◈   │               6월 신제품 런칭 이메일                │  [ ⋮ ]              │  ← 헤더
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  ┌─────────────────────────────────────────────────────────────────────────┐   │
│  │  (회색 캔버스 배경)                                                       │   │
│  │                                                                           │   │
│  │  ┌──────────┐       ┌──────────┐       ┌──────────┐                      │   │
│  │  │ 캠페인   │ ────▶ │ 이메일   │ ────▶ │ 주소록   │ ─ ─ ▶ ...           │   │
│  │  │  목적    │       │  작성    │       │          │                      │   │
│  │  └──────────┘       └──────────┘       └──────────┘                      │   │
│  │                                                                           │   │
│  │        ┌──────────┐       ┌──────────┐                                   │   │
│  │  ... ─▶│  발송    │ ────▶ │  발송    │                                   │   │
│  │        │  설정    │       │  확인    │                                   │   │
│  │        └──────────┘       └──────────┘                                   │   │
│  │                                                                           │   │
│  └─────────────────────────────────────────────────────────────────────────┘   │
│                                                                                 │
│             ┌───────────────────────────────────────────────────┐              │
│             │  [⛶ 전체보기] │ [‹ 이전]  ● ─ ○ ─ ○ ─ ○ ─ ○  [다음 ›] │ [공유]  │  ← 하단 툴바
│             └───────────────────────────────────────────────────┘              │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 노드 연결 구조

```
[캠페인 목적] ──▶ [이메일 작성] ──▶ [주소록] ──▶ [발송 설정] ──▶ [발송 확인]
     ①                ②               ③               ④               ⑤
```

**노드 상태 색상 가이드**

| 연결선 색 | 의미 |
|---------|------|
| 회색 점선 | 아직 설정 안 됨 |
| 파랑 점선 | 설정 중 (editing) |
| 검정 실선 | 설정 완료 (done) |

> 하단 툴바의 **`이전 / 다음`** 버튼으로 노드 사이를 부드럽게 이동할 수 있습니다.

## STEP 3 — 캠페인 목적 노드 설정

**[캠페인 목적]** 노드 카드를 클릭합니다.  
→ 클릭한 위치에서 확장되는 **설정 모달** 이 열립니다.

```
┌──────────────────────────────────────────────────────────────────┐
│                    어떤 이메일을 보낼 건가요?                        │
│           유형을 선택하면 맞춤 템플릿과 AI 설정이 자동으로 준비돼요   │
│                                                                    │
│  ┌────────────────┐  ┌────────────────┐  ┌────────────────┐       │
│  │  📢 프로모션   │  │  📰 뉴스레터   │  │  🤘 온보딩     │       │
│  │ 할인·이벤트·  │  │ 정기적인 콘텐츠 │  │ 신규 구독자    │       │
│  │ 신제품 알림   │  │ ·소식 공유     │  │ 환영·안내      │       │
│  │               │  │               │  │               │       │
│  │ 이런 상황에   │  │               │  │               │       │
│  │ 써요          │  │               │  │               │       │
│  │ • 시즌 세일   │  │               │  │               │       │
│  │ • 신제품 출시 │  │               │  │               │       │
│  └────────────────┘  └────────────────┘  └────────────────┘       │
└──────────────────────────────────────────────────────────────────┘
```

### 조작 방법

1. 세 카드 중 하나를 클릭합니다. (예: **프로모션**)
2. 카드 우상단에 ✓ 체크 마크가 표시되면 선택 완료.
3. 선택 즉시 모달이 닫히고 노드가 **자동저장** 됩니다.

> 선택한 유형은 AI 에이전트 프롬프트에 자동 주입되어 이메일 초안 품질을 높입니다.

## STEP 4 — 이메일 작성 노드 설정

**[이메일 작성]** 노드 카드를 클릭합니다.

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│  [블록 에디터 — 왼쪽 패널]                    [AI 어시스턴트 — 오른쪽 패널]        │
│                                                                                    │
│  발신자: _______________________        ┌──────────────────────────────────────┐  │
│  제목:   _______________________        │  🤖 AI 어시스턴트                    │  │
│                                         │                                      │  │
│  ┌──────────────────────────────────┐   │  [모델 선택: Claude / GPT / Gemini]  │  │
│  │  이메일 본문 미리보기              │   │                                      │  │
│  │                                  │   │  ┌──────────────────────────────┐   │  │
│  │  [블록 드래그 영역]               │   │  │ 어떤 이메일을 만들어 드릴까요? │   │  │
│  │  + 블록 추가하기                  │   │  └──────────────────────────────┘   │  │
│  │                                  │   │                                      │  │
│  └──────────────────────────────────┘   │  ┌──────────────────────────────┐   │  │
│                                         │  │  메시지 입력...          [↑]  │   │  │
│  [버전 관리]  v1  v2  + 새 버전         │  └──────────────────────────────┘   │  │
│                                         └──────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────────────────────────┘
```

### 조작 방법 (AI 어시스턴트 사용)

1. 오른쪽 패널에서 **모델**을 선택합니다.  
   (마이페이지에서 등록한 API 키에 따라 선택지가 표시됩니다)

2. 채팅창에 원하는 내용을 입력합니다.  
   예) `"신제품 런칭 프로모션 이메일 초안 만들어줘. 할인율 20%, CTA는 '지금 구매하기'"`

3. AI가 응답하면서 자동으로 **`updateEmailConfig` 도구** 를 호출합니다.
   - 제목(subject), 미리보기(previewText) 자동 입력
   - 블록(Text, Image, Button, Hr 등) 자동 생성

4. 좌측 에디터에서 블록을 **드래그**하여 순서를 바꾸거나, 직접 수정할 수 있습니다.

5. 완성되면 모달을 닫습니다. 변경 내용은 자동저장됩니다.

> **사용 가능한 블록 종류**  
> `Text` · `Image` · `Button` · `List` · `Hr` · `TwoColumn` · `SnsShare` · `SnsLinks` · `VideoPreview` · `Html` · `Footer` · `Spacer`

## STEP 6 — 발송 설정 노드 설정

**[발송 설정]** 노드 카드를 클릭합니다.

```
┌────────────────────────────────────────────────────────┐
│                      발송 설정                          │
│                언제, 누가 보낼지 설정해주세요            │
│                                                         │
│  발신자                                                 │
│  ┌─────────────────────────────────────────────────┐   │
│  │  📧  Gmail 연동됨                        [이동 ↗] │   │  ← Gmail 이미 연동됨 (초록)
│  │      마이페이지 → 외부 서비스에서 변경 가능       │   │
│  └─────────────────────────────────────────────────┘   │
│                                                         │
│  이메일 제목 *                                    0자   │
│  ┌─────────────────────────────────────────────────┐   │
│  │  이메일 제목을 입력해주세요                       │   │
│  └─────────────────────────────────────────────────┘   │
│                                                         │
│  미리보기 텍스트  ℹ️                                    │
│  ┌─────────────────────────────────────────────────┐   │
│  │  받은 편지함 목록에서 제목 옆에 보이는 텍스트예요  │   │
│  └─────────────────────────────────────────────────┘   │
│  비워두면 이메일 본문 첫 줄이 자동으로 표시돼요          │
│                                                         │
│  🕐 발송 시간                                           │
│  ● 즉시 발송                                            │
│  ○ 예약 발송    [날짜/시간 선택]                        │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │                      저장                        │   │  ← Gmail 연동 + 제목 입력 시 활성화
│  └─────────────────────────────────────────────────┘   │
└────────────────────────────────────────────────────────┘
```

### 조작 방법

| 필드 | 입력 내용 | 필수 여부 |
|------|---------|---------|
| 발신자 | Gmail 연동됨 표시 확인 (이미 완료) | ✅ 필수 |
| 이메일 제목 | 수신자 받은편지함에 표시될 제목 (40자 이내 권장) | ✅ 필수 |
| 미리보기 텍스트 | 제목 옆에 흐리게 보이는 보조 텍스트 | 선택 |
| 발송 시간 | 즉시 발송 또는 예약 날짜/시간 선택 | ✅ 필수 |

1. 이메일 제목을 입력합니다.  
   예) `[SALE] 6월 신제품 20% 할인 — 지금 바로 확인하세요`
2. 미리보기 텍스트를 입력합니다. (선택)  
   예) `6월 한 달만! 인기 아이템 특별가`
3. 발송 시간을 선택합니다. (즉시 또는 예약)
4. **`저장`** 버튼 클릭.

### 자동 검증 항목

| 항목 | 통과 조건 | 실패 시 |
|------|---------|--------|
| ✅ Gmail 연동 상태 | ExternalToken에 GMAIL 존재 | 발송 버튼 비활성 |
| ✅ 수신자 이메일 유효 | `@` 포함 | 발송 버튼 비활성 |
| ✅ 이메일 제목 입력됨 | 비어있지 않음 | 발송 버튼 비활성 |
| ⚠️ 미리보기 텍스트 | 선택 사항 | 경고만 표시 |
| ✅ 유형별 체크리스트 | 캠페인 유형 선택됨 | 참고용만 |

### 최종 발송 조작 방법

1. 검증 항목이 모두 ✅ 통과됨을 확인합니다.
2. **`✉ 지금 발송하기`** 버튼을 클릭합니다.

3. 확인 다이얼로그가 표시됩니다.

```
┌─────────────────────────────────┐
│       정말 발송할까요?            │
│                                  │
│  recipient@company.com 에게      │
│  지금 바로 발송돼요               │
│                                  │
│       [취소]      [✉ 발송하기]   │
└─────────────────────────────────┘
```

4. **`발송하기`** 클릭 → `POST /api/email/send` 요청

5. 발송 완료 화면이 표시됩니다.

```
┌────────────────────────────────┐
│                                 │
│        ✉                        │
│                                 │
│   발송이 완료됐어요!             │
│                                 │
│   recipient@company.com         │
│                                 │
│   [캠페인으로 돌아가기]          │
└────────────────────────────────┘
```

## 오류 상황별 대처법

| 상황 | 원인 | 해결 방법 |
|------|------|---------|
| `Gmail 연동 상태` ❌ | Gmail OAuth 토큰 없음 | 마이페이지 → 이메일 토큰 탭 → Gmail 연동하기 |
| `수신자 이메일 유효` ❌ | 이메일 형식 오류 또는 미입력 | 주소록 노드 재클릭 → 이메일 수정 |
| `이메일 제목 입력됨` ❌ | 제목 미입력 | 발송 설정 노드 재클릭 → 제목 입력 |
| AI 모델 선택 불가 | API 키 미등록 | 마이페이지 → AI API 키 탭 → 키 등록 |
| 발송 실패 (네트워크) | Gmail SMTP 오류 | 마이페이지에서 Gmail 토큰 재연동 |

## 전체 흐름 다이어그램

```
/ko 홈
  │
  ├─ 제목 입력: "6월 신제품 런칭 이메일"

        │

        │
        ▼
  플로우 편집기 로드
  GET /api/flow/[id]  →  initFromDefinition()
        │
        ▼

  ┌─────────────────────────────────────────────────────┐
  │  [캠페인목적] → [이메일작성] → [주소록] → [발송설정] → [발송확인]  │
  └─────────────────────────────────────────────────────┘
        │
        ├── STEP 3: [캠페인목적] 클릭 → 유형 선택(프로모션) → 자동저장
        │          PATCH /api/flow/[id]  { definition }
        │
        ├── STEP 4: [이메일작성] 클릭 → AI 채팅
        │          POST /api/email/agent  →  SSE 스트리밍
        │          tool: updateEmailConfig({ subject, blocks[] })
        │          PATCH /api/flow/[id]  { definition }
        │
        ├── STEP 5: [주소록] 클릭 → 이메일 입력 → 저장
        │          PATCH /api/flow/[id]  { definition }
        │
        ├── STEP 6: [발송설정] 클릭 → 제목·미리보기·시간 입력 → 저장
        │          PATCH /api/flow/[id]  { definition }
        │
        └── STEP 7: [발송확인] 클릭 → 자동 검증 통과 → 발송하기
